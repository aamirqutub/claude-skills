# examples/

Two real reference outputs, both produced with this brand skill at the studio it was built
at, then sanitised for public release. They exist to set the bar: a model calibrates against
a finished example far better than against an adjective.

- **`em-capability-onepager.html`** — a single-page capability statement on a dark canvas.
  One typographic hero moment, a stat row, a selected-work list, a closing CTA.
- **`em-proposal-baycare.html`** — a four-page client proposal for a fictional client
  (BayCare). Cover, an editorial "opportunity" page, a structural phases-and-scope grid, and
  a pricing-and-signature page. It shows how far the composition can travel — editorial to
  modular to decision-grade — while the DNA holds.

Read them together and notice how *differently* the two compose. That variation, off one
small DNA, is the whole argument of the skill.

## What was changed for release

These shipped as genuine studio work, so a few things were anonymised — nothing that affects
the composition:

- Real client and staff names replaced with generic descriptors or placeholder names.
- Direct contact details (phone, email) removed; the public domain kept.
- Proposal pricing figures redacted to `$XXX,XXX` placeholders. The layout of the pricing
  page is the instructive part, not the numbers.

When you adapt this skill, replace these with your own real, un-redacted outputs — that's
what makes the bar real for your work.
