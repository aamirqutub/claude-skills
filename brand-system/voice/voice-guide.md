## Voice in one sentence

> {{BRAND_NAME}} speaks like [who — a specialist, a guide, a peer, a challenger] who
> [what they've stopped doing — trying to impress you, over-explaining, hedging].

One sentence. If you can't get it into one, you don't know the voice yet.

## Tone spectrum

Define each axis as *this, not that*. The negative half does the real work — it's what
stops a model from overshooting.

- **Confident, not arrogant**
- **Direct, not blunt**
- **Warm, not cosy**
- **Plain, not dumbed-down**
- **[axis], not [failure mode]**

## Write like this

- **Active voice.** "We built it" beats "It was built."
- **Specific over abstract.** A number beats an adjective.
- **One idea per paragraph.**
- **Name people.** Attribute quotes to a named human, never "the team said."
- **Acknowledge trade-offs.** Honesty about what doesn't work buys credibility for what does.
- **[Your locale's spelling convention.]** e.g. Australian English — colour, organisation, recognise.

## Don't write like this

The banned-words list is the single highest-leverage part of this file. Be specific and
be ruthless — a model will reach for these by default.

- **Banned:** leverage, utilise, facilitate, synergy, paradigm, ecosystem, journey
  (figurative), passionate, exciting, revolutionary, disruptive, transformative,
  innovative, cutting-edge, best-in-class, world-class, industry-leading, robust,
  seamless, frictionless, holistic
- **No corporate AI-isms.** "Tapestry of solutions", "weave together insights" — kill on sight.
- **No throat-clearing intros.** Never "In today's rapidly evolving landscape..." Start with the point.
- **No "we are pleased to" / "we are excited to".** Just say what you're doing.

## Pronoun rules

- **"We"** = the company. Use freely.
- **"I"** = attributed quotes from a named individual only.
- **"You"** = the reader. Use to direct them.

## Voice variants by context

Same DNA, different register. Without this section, everything comes out at proposal
formality — including the social posts.

| Context | Register |
|---|---|
| Proposals, client documents | Most direct. Specific numbers, named outcomes, clear scope. |
| Capability statements | Slightly more declarative. First impression. |
| Internal docs | Loosen up. Shorthand fine. |
| Website | Punchier. The most opinionated surface. |
| Social | Loudest. One idea per post. |
| Founder's own speaking and writing | **This is a person, not the brand. Keep it separate.** |

## Place and provenance

If the brand is *from* somewhere, decide the hierarchy and write it down, because the two
are different jobs and collapsing them costs you both:

- **Home** — where you actually are. This is identity. Don't overwrite it for reach.
- **Market served** — where the buyers are. This is positioning copy.

State it as a relationship, not a substitution: *"serving [market] from [home]."* True,
and it earns both searches.

## When in doubt

> Would [the founder] say it that way to a friend over coffee, just slightly more polished?
